# EvoHallu / mod1: результаты коротких эволюционных запусков

**Кампания:** 15 октября 2026 года.

**Задача:** проверить новые модели — авторы Python-детекторов и измерить пользу эволюционной обратной связи. Все результаты ниже рассчитаны по исходной колонке **`is_hallu`**, без изменения меток UHEAD.

## 1. Модели и протокол

| Компонент | Использованная модель / метод |
| --- | --- |
| **Базовая модель — источник признаков** | **Llama-3.1-8B-Instruct**, общая для всех основных экспериментов |
| **Исходная модель — автор кода** | **GPT-OSS-120B** из исходной конфигурации; в этой кампании заново не запускалась |
| Новые авторы детекторов | Qwen3.8-27B, Laguna XS 2.1, Qwen3.5-9B, Qwen3.5-4B |
| **Базовый детектор** | **Sequence NLL**: `score = −Σ log p(token_t)` |

Модели-авторы генерировали код детекторов. Качество этого кода проверялось на общих признаках Llama. Веса языковых моделей не дообучались; разметка train использовалась для оценки и отбора программ.

- **Поиск:** до 30 раундов, по два кандидата в раунде; до 60 запросов на запуск.
- **Повторы:** по два запуска для Qwen27B, Laguna и Qwen9B; один для Qwen4B. У 4B выполнен 21 раунд / 42 запроса — сработала остановка после трёх подряд неудачных раундов.
- **Всего основной эволюции:** семь запусков, 402 запроса, 283 валидных кандидата. Валидность означает успешное исполнение и конечную оценку на train/validation, а не отдельную новую идею.
- **Данные поиска:** PopQA train, 7 007 строк; разбиение на 5 605 train и 1 402 validation, seed 441.
- **Генерация:** temperature 0.7, top-p 0.8, top-k 20, до 4 096 выходных токенов; контекст сервера 16K.
- **Оценка:** девять датасетов, 97 488 утверждений. Сначала программа выбиралась по validation и фиксировалась, затем оценивалась на тестовых наборах.

## 3. Контроль: что даёт эволюция

Проверены два режима без эволюционной обратной связи:

- **`independent`:** генерация с нуля, без примеров из популяции.
- **`baseline_seeded`:** каждый запрос содержит один и тот же исходный пример; улучшенные программы не возвращаются в запрос.

Ниже seed 1048; в каждой сравниваемой ветке выполнено 60 запросов.

| Автор / контроль | Эволюция | Контроль | Эволюция − контроль, п.п. | Парный 95% интервал |
| --- | --- | --- | --- | --- |
| Laguna / independent | 69.23 | 68.31 | **+0.93** | 0.67 … 1.19 |
| Laguna / baseline_seeded | 69.23 | 68.53 | **+0.70** | 0.42 … 0.99 |
| Qwen27B / independent | 68.53 | 69.47 | **−0.94** | −1.25 … −0.64 |
| Qwen9B / baseline_seeded | 69.54 | 69.80 | **−0.26** | −0.69 … 0.11 |

У Qwen27B здесь используется seed 1048 для обеих веток. Значение 69.80 из основной таблицы относится к другому эволюционному запуску — seed 1047; подставлять его в этот контроль нельзя.

Интервалы получены из 500 парных bootstrap-повторов по группам одинаковых нормализованных утверждений. Они относятся к фиксированной коллекции девяти датасетов, не учитывают разброс между запусками поиска и не скорректированы за множественные сравнения.

**Наблюдение:** эволюция помогла Laguna, но универсального выигрыша нет. Для Qwen9B интервал разности с постоянным примером включает ноль. Сравнение с `baseline_seeded` точнее отделяет пользу обратной связи: `independent` одновременно убирает и обратную связь, и примеры кода.

Отдельный Qwen9B independent остановился после 12 запросов: одна валидная программа, сохранён базовый NLL. Он не включён в таблицу равных 60-запросных бюджетов.

## 4. Упрощение найденных формул

| Проверка | Исходная формула | Упрощённая | Изменение ROC-AUC, п.п. |
| --- | --- | --- | --- |
| Qwen27B: линейно взвешенный NLL в float64 | 69.7969 | 69.7926 | **−0.0043** |
| Laguna: удаление компонента дисперсии top-1 при сохранении slope и entropy range | 69.2343 | 69.2192 | **−0.0151** |

Формула Qwen27B практически сводится к `n × weighted_mean(NLL, weights=1…n)`, то есть усиливает вклад последних токенов. Разница с исходной записью включает эффект округления. Коэффициенты упрощений не подбирались на test; варианты фиксировались до их тестовой оценки. В этих наблюдениях часть сложности можно убрать почти без потери качества.
