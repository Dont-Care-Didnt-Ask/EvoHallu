## Changes to existing search code since `52ff260`

The modified search implementation is [extension_trial.py](../../src/experiments/extension_trial.py). Its changes are narrowly identifiable:

| Location | Added behavior | Scientific consequence |
| --- | --- | --- |
| `_eval_worker` | `trial.save_train_predictions` optionally retains training score vectors, in addition to the existing validation vectors. | Enables training-only behavioural diagnostics without recomputing model features or using test scores. Default remains off. |
| `build_prompt` | New `frozen_context` mode returns the saved context for the corresponding round and requires its context count to match the round count. | Allows matched prompt policies to receive the same historical parents; this is a separate screen, not adaptive evolution. |
| `run_trial` configuration checks | Validates the prompt policy, refuses to combine non-original policy intervention with legacy `structured` mode, and verifies the frozen-context manifest hash. | Avoids silently bundling incompatible prompt interventions or changing matched contexts. |
| Resume checks | Adds immutable comparisons for prompt policy, frozen-context hash and training-prediction retention. | Refuses resumption under changed experimental conditions. |
| Request construction and ledger | Builds one policy-specific chat per sibling; saves `candidate_prompts_*.json`; records policy, deterministic request seed and actual chat SHA-256. | The persisted artifact is the issued prompt, including sibling-specific instructions. |
| Prediction persistence | Saves baseline and valid-candidate training arrays when requested. | Supports rank/probe, precision and inactive-branch audits using the original execution outputs. |
| Final export | Optionally exports validation ranks up to the configured shortlist limit, with code, candidate identity, validation score and source hash. Baseline is inserted first before a stable descending sort. | Preserves baseline fallback and baseline-first ties. Retained ranks are selected by validation; source-identical ranks may subsequently share predictions. |

The accompanying [trial configuration](../../configs/config_uq_trial.yaml) adds defaults `prompt_policy: original`, `save_train_predictions: false` and `shortlist_size: 1`, and documents the new mode. These defaults retain the earlier single-winner/original-prompt behavior. The new [study configurations](../../configs/next_experiments/) explicitly opt into saved training arrays, top-three exports, policy/seed settings and bounded budgets. Their thirty rounds use two attempted proposals per round. The study config sets the consecutive-failed-round limit to 31 so it cannot truncate a thirty-round arm merely because several successive proposals fail; invalid proposals still count toward the request budget.

[test_extension_trial.py](../../tests/test_extension_trial.py) now exercises frozen contexts, actual sibling prompts through a stub HTTP server, saved training vectors, shortlist export and refusal to resume with a changed prompt policy. It also retains the earlier ordinary-trial checks.

## Prompt policies and explicit runtime interventions

The new [prompt_policies.py](../../src/experiments/prompt_policies.py) deep-copies chats and returns the original prompt content unchanged for `original`. `neutral` replaces the inherited prescribed-formula block with open formula choice. `diverse` additionally assigns alternating refinement/exploration roles and rotates signal-family suggestions. `compositional` asks for complementary weighted features and explicitly imposes no feature-count ceiling. These are declared prompt interventions; a higher valid-source count alone is not evidence of useful behavioural diversity.

Two standalone wrappers add other interventions without rewriting the pinned implementation files:

- [overnight_sampler_trial.py](../../scripts/overnight_sampler_trial.py) intercepts only the score-group weighting call made by `Island.get_prompt`. For eligible groups it uses `0.8 × average_rank(fitness)/sum(ranks) + 0.2/n`. The caller check preserves the separate within-group shorter-source softmax. Quantile eligibility, island selection, sampling without replacement and within-group preference remain inherited. It restores the original function afterward and saves actual eligible pools, probabilities and hook counts.
- [overnight_interface_trial.py](../../scripts/overnight_interface_trial.py) temporarily wraps `prompt_policies.candidate_prompt` for an explicit neutral-only interface-and-metric arm. It appends the actual constructor, ragged batch dictionary, `L+1` top-k versus `L` observed-logprob alignment, conditional top-512 normalization, finite-precision/API guidance and higher-is-hallucination direction. It preserves formula freedom, uses no repair calls, and verifies the saved issued prompts and hashes. This bundles interface and metric clarification; it cannot isolate shape guidance alone.

The historical [programs_database.py](../../src/packing/funsearch/programs_database.py) remains **byte-identical to the original ZIP**. The parent-sampling experiment changes runtime behavior through the declared wrapper, not through an undisclosed sampler source edit.

## Scoring, selection, provenance and diagnostics

[overnight_eval.py](../../scripts/overnight_eval.py) stages uniquely named immutable detector sources, records source/run/selection identities and generates explicit CPU cached-evaluation commands. It can additionally freeze training-best candidates or validation ranks 2–3 as labelled diagnostics. Candidate key collisions cannot silently substitute one run's program for another.

[overnight_report.py](../../scripts/overnight_report.py) merges saved predictions only when shared arrays agree, retains directed and per-dataset-folded AUROC, reports duplicate-disjoint sensitivity and reads paired claim-bootstrap arrays. Partial/unverified request budgets are excluded from primary seed groups; available seed counts remain explicit. Matched feedback, sampler and interface contrasts use **neutral evolution** with the same writer, seed and request count. Original evolution is a separately named reference. A partially populated group is not a final three-seed result.

[reconcile_paper_reporting.py](../../scripts/reconcile_paper_reporting.py) reproduces the author's clarified `max(AUC,100−AUC)` transform **within each method and dataset before averaging**. The isolated optional [overnight_shortlist_secondary.py](../../scripts/overnight_shortlist_secondary.py) waits for all twelve full-budget adaptive runs and their original nine-dataset predictions. It preserves all validation rank slots, including baseline and source-identical aliases, and scores only unique additional ranks 2–3 in its own registry. Its top-three diagnostic averages **individual method AUROCs**, not predictions, ensembles or test-best maxima. Active timing starts after readiness; waiting has its own absolute gate.
